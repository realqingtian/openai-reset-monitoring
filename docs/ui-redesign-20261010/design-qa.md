## 比对迭代与修复

1. **[P2] 窄屏英文检查按钮被裁切。** 320 × 740 时按钮右边界超出 320；证据 `mobile-320-before.jpg`。极窄屏改为两列两行，390px 仍为一行，并固定检查文案不换行。修复后见 `mobile-320-fixed.jpg` 与最终 `mobile-320-final.jpg`：所有顶部操作右边界最大 293，页面 scrollWidth = 320。
2. **[P2] 画布环境光比选定稿偏重。** 第一次同图比对位于 `implementation/iteration-1/`。将已有环境光令牌的整体透明度降至 0.55，导航外缘改为内容层边缘色。重新构建、捕获并检查最终三页并排图，已回到更轻的画布。
3. **[P2] 统计动画使全页截图/未进入视口的数据暂显示 0。** 第一版同图中的底栏出现 0。统计与热力总数以实际值初始化，并跳过起点等于终点的计数动画。最终浏览器读取为“5 窗口内推文 / 2 命中公告”，与隔离 DEMO API 一致。
4. **[P2] 模态浮层关闭后的焦点恢复与 Tab 边界。** React 移除 dialog 后，原生恢复不能稳定返回触发按钮。保存并显式恢复触发焦点，并对首末输入/按钮圈定 Tab。最终验证：Tab 从登录按钮回用户名，Shift+Tab 从用户名回登录按钮，Escape 后焦点回管理员登录。语言菜单支持上下箭头、Home/End、Escape，并归还触发焦点。

5. **[P2] 浮层透出背景文字，干扰阅读。** 移动登录窗旧截图 `login-mobile-light.jpg` 可见正文透入字段；底栏处于顶部导航的嵌套背景采样范围。登录表单改为主题实体底色，保留浮层高光、阴影与遮罩；底部导航用 Portal 放到 body，内容层不透明度提高至浅色 0.90 / 深色 0.92。最终 `login-mobile-final.jpg`、`login-mobile-dark-final.jpg` 与移动公告截图复核通过；390px 底栏 bottom = 830，移动端不在 header 内，回到 1440px 恢复 header 内且只有一个导航。

修复后无待处理的 P0/P1/P2 视觉或核心交互问题。最终三页同图、导航近景、移动表单与深浅色截图已复核。
