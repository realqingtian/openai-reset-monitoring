三套共同的完整功能契约：
1. 全局与鉴权
   - 配置站点名称、品牌、DEMO 标识。
   - 公告动态 / 重置节奏 / 系统状态三页导航及当前页面状态。
   - 被监控账号、正常 / 未配置 / 待首次检查 / 全部源失败、最近检查时间。
   - 立即检查：正常、请求中、禁用、成功、失败、401 登录后自动重试。
   - 浅色 / 深色 / 跟随系统；中文 / English / 自动跟随浏览器语言。
   - 鉴权关闭时不显示登录入口；开启时显示管理员登录 / 已登录用户 / 退出。
   - 用户名、密码、取消、登录；空值、错误账号、网络失败、提交中、登录过期。
   - 发送测试通知仅在 debug 可见：无渠道、全部成功、部分失败、请求失败反馈。
   - 24H 推文数、命中数、轮询间隔；页面 60 秒自动刷新说明与页脚。
2. 公告与帖子
   - 最新命中公告和完整原文；作者名、账号、真实头像及缺失兜底。
   - 相对时间和悬停 UTC+0 / 访问者本地时区的秒级时间；主公告绝对时间。
   - 数据源、命中、回复、已推送、AI 已复核、AI 判定无关标签与规则 / AI 原因提示。
   - 关键词由 hl() 安全高亮；外链由 safeUrl() 校验。
   - 原文 X 链接；翻译展开 / 收起、加载、同语、失败及重试、免费或 AI 厂商标识。
   - 翻译按目标语言缓存，同帖不同位置分别控制展开，刷新不丢结果。
   - 最近帖子 / 历史命中切换，不增加现有系统没有的搜索或筛选接口。
   - 滚动列表、自动加载、加载更多、去重、已加载数量、失败重试、到底、空状态。
   - 匿名窗口不超过 24h，管理员按现有配置窗口；不改权限范围。
3. 重置节奏
   - 下次预测时间、倒计时、上次命中、平均间隔、30 天命中、26 周累计命中。
   - 样本不足不预测；预测逾期继续等待；历史推算仅供参考，不宣称个人额度已重置。
   - 26 周热力图、日期轴、数量图例、鼠标提示；点击命中日展开明细、收起、X 链接。
   - 命中历史包含完整阅读、翻译和加载能力；AI 判定无关不计入节奏样本。
4. 月历与日期明细
   - 实际月份、上一月 / 下一月、正确星期和实际周数、当月额度重置 / 重置卡计数。
   - 访问者本地日期归组、今日、非当月日期、点击选择 / 再点击收起。
   - 多事件圆点与 +N；实际事件实心、预测事件空心环。
   - 已生效 / 待生效 / 应已生效 / 晚于预计图例；保持现有 6h / 24h 展示约定。
   - 明细类型、生效或预测时间、全文、X 原文链接、预测依据；无记录及加载失败状态。
5. 系统与日志
   - 数据源启用 / 配置 / 凭证不足 / 待检查 / 正常 / 失败次数 / 最后错误。
   - 飞书、钉钉、企微、Bark、Telegram 的实际配置状态；未配置不伪装已送达。
   - AI 厂商、模型、复核开启 / 关闭、AI 优先翻译、未配置时免费翻译及不复核说明。
   - 日志时间、来源、成功 / 失败、数量、耗时、错误提示。
   - 最近最多 200 条、保存 30 天说明；10 条每页、上下页、禁用边界、空列表。
6. 全套视觉规则与移动端
   - 同一套页面使用统一字体层次、按钮高度、圆角、图标线宽、间距、焦点和反馈。
   - 页面按信息职责布局，系统页不重复放完整日历或预测旁栏。
   - 浅深主题的形状与结构一致，颜色仅使用现有 CSS 变量及其主题取值。
   - 手机保留三个页面、全部操作和状态；长正文 / 日历 / 日志有明确排布。
   - 实施后必须验证 1440、1024、768、390、320px 及 documentElement.scrollWidth。
   - 文案继续走中英 i18n；动画继续用现有 React Bits；不引 Tailwind、字体或依赖。
